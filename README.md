# Beatrice Beauty Studio 💇‍♀️

A modern, elegant booking and service showcase website built for a luxury hair studio based in Accra, Ghana.

##  Overview

Beatrice Beauty Studio is a full-stack web application designed to provide clients with a seamless experience for discovering services and booking appointments at Accra's premier hair studio.

##  Features

- Service showcase with detailed descriptions
- Online appointment booking system
- About and contact pages
- Fully responsive design across all devices
- Clean, modern UI with elegant typography

##  Tech Stack

- **Backend:** Laravel 13.8 with Blade templating
- **Frontend:** Tailwind CSS via Vite
- **Database:** MySQL
- **Local Development:** Laravel Herd
- **Editor:** VS Code
- **Install:** Clean Laravel install — no starter kit
